Live Chat Moderation

This is the same live.html chat, in real time — search it, click any name to pull up everything they've said, and ban, timeout, or delete from there.

Banning blocks a browser at the database level (Firestore itself rejects the write, not just a check in this page) and deletes that browser's previous messages. It targets the device, not the name — a banned visitor typing a new username on the same browser is still blocked. A different browser or device isn't, since nothing on a static site like this one can reach that far. "Last known IP" below is a reference clue only (e.g. spotting two names that share one), not something this can actually block.
