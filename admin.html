Track List

Bulk-adds every video in a YouTube (or YouTube Music) playlist, with titles filled in automatically. No API key needed — this goes through Piped, a free open-source YouTube mirror, instead of Google's official API. That's a volunteer-run, unofficial service though: if an import fails, it's usually worth just trying again (it tries a few public Piped instances in turn), and it isn't something to rely on if it ever stops working entirely.
